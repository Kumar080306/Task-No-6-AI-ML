# K-Nearest Neighbors (KNN) Classification - Iris Dataset 

This project implements a basic **K-Nearest Neighbors (KNN)** classification model using the popular **Iris dataset**. It demonstrates how to preprocess data, train a KNN classifier, evaluate the model, and visualize decision boundaries.

##  Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Steps Covered
1. Load and explore the Iris dataset
2. Normalize features using StandardScaler
3. Train a KNN model using `KNeighborsClassifier`
4. Evaluate using accuracy score and confusion matrix
5. Visualize decision boundaries (2D)

##  Files
- `Task_No_6.ipynb` – Main Python script for training and visualization
- `Iris.csv` – Dataset file
- `README.md` – Project description

##  How to Run
1. Upload `Iris.csv` to your workspace.
2. Run `https://colab.research.google.com/drive/1hhqP2WUaSIZlAKTC-UXk6PW3BlOBzJV2#scrollTo=b6VzEW4B2XD5` in a Google Colab.
3. Observe the model accuracy and plots.

## Output
- Model accuracy on test data
- Confusion matrix plot
- Decision boundary visualization (2 features)
